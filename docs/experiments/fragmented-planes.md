# Fragmented Planes prototype

Branch: `experiment/fragmented-planes`

The photograph is divided into soft luminance-derived bands. Each band samples
the original source with a small, different parallax offset, producing a
continuous 2.5D plane relationship without arbitrary rectangles or semantic
segmentation.

Low and mid energy move the planes slowly. Transients add a restrained
cross-axis separation. The image can remain recognizable because every layer
still comes from the source photograph.

The engine does not use particles. It is an image-surface experiment, not a
claim of true depth reconstruction.
