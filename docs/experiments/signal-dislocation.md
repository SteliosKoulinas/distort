# Signal Dislocation prototype

Branch: `experiment/signal-dislocation`

The photograph remains a continuous texture. Spectral flux and transient
energy selectively open individual scanline regions. Those rows receive a
small horizontal displacement and restrained RGB channel misalignment. A
local luminance boundary gives the event a relationship to the source image,
instead of applying a permanent random glitch overlay.

The engine does not use particles. Between signal events it returns close to
the source photograph.

Validation: type check, tests and production build are required before this
prototype is added to the shared review branch.
